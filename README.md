# UCA1 ceRNA analysis in pancreatic cancer

Code accompanying:

> Askari N, Shad Pirouz M, Mafikandi V, Hadizadeh M, Mousavi SZ.  
> The lncRNA UCA1 enhances pancreatic cancer EMT by regulating miR-708-5p and miR-135b-5p: a bioinformatics approach.  
> *Iranian Journal of Public Health*. 2024;53(7):1659-1669.  
> https://doi.org/10.18502/ijph.v53i7.16060

## What this repository contains

Bioinformatics analysis of the UCA1–miR-708-5p / miR-135b-5p axis and EMT in pancreatic cancer.

## Data policy

Public datasets only (GSE119794). No identifiable patient data.
